### 处理分支

| 模型返回情况 | 程序处理 |
|---|---|
| 方向写成 `unpredictable` / `unknown` / `无法预测` / 空值 / 非法类型 | 丢弃该方向的模型结论，按教材周期规则本地算方向与解释 |
| 显式 `unpredictable=true` | 同上 |
| 方向为 neutral 且正文说"难以预测/无法判断/存在不确定性" | 同上（避免界面出现"无法预测"字样） |
| 方向明确（含 bullish/up/看涨 等别名）+ 正常正文 | 保留模型原文，仅做别名归一 |
| `next_bar_prediction` / `next_cycle_prediction` 整段缺失 | 按本地规则补算 |
| `order_type` 非法 | 归为"不下单"，并给出本地说明（不产生报错弹窗） |
| `reasoning` 为空 | 补本地说明 |
| 网络/限流/额度错误 | 仍然如实报错（无法本地伪造一次模型调用） |

### 本地方向的计算依据

来自 `prompt_engineering/市场诊断框架.txt` 的周期判定：先用已收盘K线算当前结构（效率、重叠、摆动结构、回撤比例、20EMA斜率），

两者冲突或都走平则给中性；交易区间/极端区间一律中性。
解释文本会写明判出的结构、效率、重叠、EMA方向与回撤比例，并说明"区间延续需收盘突破确认"或"趋势中回撤按顺势处理"。

模型原始方向与原文保存在 `model_direction_raw` / `model_reasoning`，`direction_filled_by=program_rules` 标记来源，均不进可见界面。
